개인정보처리방침

MacroSuite · 최종 수정 2026-09-23

MacroSuite는 게임 위에 뜨는 매크로 오버레이입니다. 이 문서는 MacroSuite가 무엇을 수집하고, 어디에 두며, 언제 지우는지를 있는 그대로 적은 것입니다.

1. 로그인할 때 받는 것

로그인은 Auth0를 거쳐 Google 또는 GitHub 계정으로만 합니다. MacroSuite는 비밀번호를 받지도, 저장하지도, 볼 수도 없습니다. 로그인이 끝나면 다음을 받아 계정에 저장합니다.

  • 로그인 제공자와 그 제공자가 준 사용자 식별자 (예: google-oauth2|…, github|…)
  • 표시 이름
  • 이메일 주소 (제공자가 준 경우)

이메일은 계정을 알아보고 문의에 답하는 용도로만 씁니다. 광고에 쓰지 않고, 제3자에게 팔거나 넘기지 않습니다.

2. 서비스를 쓰는 동안 쌓이는 것

  • 세션 — 로그인한 기기별로 세션 하나. 만든 시각, 만료 시각, 기기 구분용 임의 식별자를 둡니다. 이 식별자는 무작위 값이고 기기의 하드웨어 정보가 아닙니다.
  • 이용 등급과 권한 — 어떤 기능을 쓸 수 있는지 판단하는 값입니다.
  • 매크로 스크립트 — 서버에 저장하기를 선택한 것만. 저장하지 않으면 스크립트는 사용자 PC를 떠나지 않습니다.
  • 관리 기록 — 운영자가 계정을 정지하거나 권한을 바꾸면 그 사실과 시각이 남습니다.

3. 수집하지 않는 것

  • 키보드·마우스 입력 내용. 매크로가 보내는 키는 사용자 PC 안에서만 처리되고 서버로 가지 않습니다.
  • 화면 캡처, 실행 중인 다른 프로그램의 내용.
  • 위치 정보, 연락처, 결제 수단.
  • 광고 식별자, 제3자 추적기. MacroSuite에는 분석 도구나 광고 SDK가 없습니다.

4. 어디에 두는가

  • 계정·세션·권한: 관리형 데이터베이스 (아시아·태평양 리전).
  • 서버에 저장한 매크로 스크립트: 비공개 저장소.
  • 로그인 상태와 앱 설정: 사용자 PC의 %LOCALAPPDATA%\MacroSuite. 로그인 정보는 Windows의 사용자 계정 단위 암호화(DPAPI)로 암호화해 저장하며, 다른 사용자 계정에서는 복호화되지 않습니다.

5. 얼마나 두는가

  • 세션: 만료되거나 로그아웃하면 무효가 됩니다.
  • 계정과 그에 딸린 데이터: 계정을 지우면 함께 지웁니다.
  • 로컬 파일: 앱에서 로그아웃하면 저장된 로그인 정보를 즉시 지웁니다.

6. 사용자가 할 수 있는 것

  • 연결된 로그인 수단을 앱에서 확인하고, 추가하거나 해제할 수 있습니다.
  • 다른 기기의 세션을 끊을 수 있습니다.
  • 계정과 저장된 데이터의 삭제를 요청할 수 있습니다. 아래 연락처로 요청하면 처리합니다.
